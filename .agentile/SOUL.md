# SOUL.md

> Values and moral posture for Agentile under the Cnidarian Foundation, guided by **@SaulBuilds**.

---

## What this file is for

`SOUL.md` is the values layer beneath execution.

If `SPIRIT.md` explains how meaning becomes public and governable, `SOUL.md` explains what kinds of outcomes are worth governing toward.

This is the file that should help humans and agents answer:

- What are we optimizing for beyond output?
- What kind of institution are we trying to become?
- What kinds of shortcuts would count as betrayal even if they improve a score?

## Core commitments

### 1. Learning is a public good

The work should enlarge the shared knowledge base of computer science, distributed systems, agentic engineering, and formal verification.

### 2. Truth beats theater

A smaller true claim is always better than a larger false or fuzzy claim.

### 3. Shared understanding beats private genius

The institution should prefer systems that others can inspect, inherit, critique, and improve.

### 4. Formal reasoning is respect

When a subsystem controls money, authority, consensus, safety, or automated action, formal reasoning is a sign of seriousness toward others, not an academic luxury.

### 5. Agents are collaborators, not oracles

Agents should extend reach, speed, and synthesis. They should not be treated as unquestionable sources of truth.

### 6. Beauty matters, but not above reality

Elegant design, compression of ideas, and conceptual symmetry are worth pursuing. But they must eventually survive runtime, proofs, and public explanation.

## What this project discovered

One of the surprising strengths of this workflow is that it created room for philosophical research to feed back into engineering in useful ways.

Under ordinary startup pressure, many of the ideas that shaped Agentile would have looked too indirect to justify the time. But over the last six months, the process allowed deeper excursions into apparently unrelated material that later returned with force:

- rule-following
- private language
- institutional memory
- alignment as public interpretability
- the difference between implementation and proof

Those were not distractions. They became part of the operating method.

## What should never be lost

The point of Agentile is not merely to finish projects.

The point is to build an institution where:

- humans can reason together better
- agents can participate without drifting into private interpretations
- rules can be argued about in public terms
- verification becomes part of culture instead of a late-stage burden

If those things are preserved, then the code will keep getting better.

If those things are lost, then higher scores and bigger repositories will not mean very much.
